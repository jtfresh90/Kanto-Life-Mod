# Kanto Life

Ambient town/route NPCs, optional Pokemon NPCs, sleep toggle + rate, and Common Courtesy knocking for [gen1recomp](https://github.com/bryanthaboi/gen1recomp).

## Install

Download the latest release zip and import it in gen1recomp **MODS**, or unpack under `mods/kanto_life/`.

## Options

**START → OPTION → KANTO LIFE**

## Auto-update

`manifest.json` sets `"github": "jtfresh90/Kanto-Life-Mod"`. The launcher reads Releases and offers **Update** when a newer installable zip is published (asset name preferably `kanto_life-*.zip` or any `.zip`).

## Compatibility

- `games: ["all"]`
- `game_version: ">=0.0.0 <10.0.0"`
- Adaptive `mod.game` / `mod.world.game` for 0.1.78–0.1.86+
