# Changelog

## [1.4.205] - 2026-10-12

### Fixed
- Fixed Gen1 voxel speech bubbles so they stay centered over NPCs.
- Fixed Gen1 fly/teleport visual swaps to use a random flying or psychic sprite immediately when the departure begins.
- Fixed Gen2 sleep prop alignment for bed, sleeping bag, and tent overlays so they no longer drift or duplicate the default sleeping sprite.
- Fixed Gen1 sleep placement so NPCs no longer sleep within 5 cells of a doorway.
- Bumped the mod manifest to 1.4.205 and kept the release marked as non-experimental.

### Notes
- This release keeps the mod on the stable 1.4.204 family build line while addressing the reported visual and placement bugs.
