# jtfresh90@kanto_life

Mod folder layout matching the gen1recomp mod-index id `jtfresh90@kanto_life`.

For a gen1recomp **source fork**, copy this folder to:

```text
mods/jtfresh90@kanto_life/
```

Or install the release zip so the launcher places it under `mods/kanto_life/` (manifest id is still `kanto_life`).

See repository root `manifest.json` / `main.lua` for the playable package, or use a GitHub Release zip.
