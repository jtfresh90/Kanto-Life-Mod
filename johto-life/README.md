# Johto Life 0.1.1

Gen 2 only (Gold / Silver / Crystal). Do not enable with Kanto Life.

## Install
Zip `main.lua` + `manifest.json` and import into gen1recomp (0.2.x supported).

## Features
- Extra outdoor/indoor NPCs with random Gen2 sprites
- Gendered English names (e.g. Chloe, Alex)
- Common Courtesy knock + walk-in eject
- JOHTO LIFE under Options
- EXTRA NPC COUNT 0 = no extras (absolute once you change the slider)
