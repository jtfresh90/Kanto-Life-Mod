# Kanto Life

Adds living towns and routes to gen1recomp.

## Features

- **Extra NPCs** with a 0–150 count (and indoor count)
- **Pokemon NPCs** (optional) that say their name and cry — does not touch Wilds
- **Sleeping NPCs** toggle + **Sleep Rate %** (default 15%)
- **Day sleepers** option
- **Common Courtesy** knocking before entering homes
- Varied ambient dialogue for crowd NPCs

## Options

Open **START → OPTION → KANTO LIFE**.

## Compatibility

- Manifest `games: ["all"]` so Gen 1 and Gen 2 boots load the mod
- `game_version: ">=0.0.0 <10.0.0"` (original through 9.9.9)
- Adaptive game facade for gen1recomp 0.1.78–0.1.86+

## Install

Drop the release zip into the in-game mod manager, or unpack under `mods/kanto_life/`.
