# Mod index submission

Copy the `jtfresh90@kanto_life/` folder into a fork of [gen1recomp-mod-index](https://github.com/bryanthaboi/gen1recomp-mod-index) under `mods/`, then open a PR to `main`.

Or use the web form: https://bryanthaboi.github.io/gen1recomp-mod-index/

Launcher auto-update already works from this repo's Releases because `manifest.json` includes `"github": "jtfresh90/Kanto-Life-Mod"`.
